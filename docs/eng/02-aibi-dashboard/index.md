## Lab Overview

In Step 1, Daniel created the `gold_customer_360` table, which contains lifetime bookings, spending, average rating, and most recent booking date for each customer. In this lab, you will create an **AI/BI Dashboard** that displays customer value, activity, and loyalty all on one screen.

## Features Used in This Lab

| Feature | Description |
|---|---|
| **AI/BI Dashboard** | Create a dashboard by arranging visualization widgets based on SQL datasets. |
| **Dataset** | A SQL query used by widgets. Multiple widgets can reuse a single dataset. |
| **Genie Code** | An AI assistant that automatically creates dashboard widgets when you request them in natural language. |

## Learning Goals

- Define dashboard datasets with SQL.
- Manually create and configure Heatmap, Histogram, Bar, and Scatter widgets.
- Create multiple widgets in natural language with Genie Code in a single prompt.
